# 눈소리 (Nunsori)

[English](README.md)

*Local Search Anything.* **N**ative **U**nified **N**atural-language **S**earch, **O**ffline **R**ecall & **I**ndex. 눈(보고)과 소리(듣는) 이 두 가지로 파일을 이해한다는 뜻의 이름입니다.

폰에 있는 파일을 온디바이스 멀티모달 임베딩 모델로 인덱싱하고, 의미와 키워드로 검색하는 Android 앱입니다. 데이터는 기기 밖으로 나가지 않습니다. AI 모델은 동반 앱 [온돌샘 / OndolSaem](https://github.com/sonanjip/ondolsaem)에서 실행되며, 온돌샘이 모델을 한 번 내려받아 다른 앱과 함께 씁니다.

*폰 안의 파일을 의미와 그 안의 글자로, 영어와 한국어 모두 찾습니다.*

이 파일로 답하는 채팅 비서는 0.10.0부터 동반 앱 [말벗다리 / Malbotdari](https://github.com/sonanjip/malbotdari)입니다. 눈소리 SDK로 이 인덱스를 씁니다. 노트(메모, 저장한 웹페이지·영상, 녹음과 그 요약)는 동반 앱 [조각보 / Jogakbo](https://github.com/sonanjip/jogakbo)에 있고, 말벗다리가 함께 읽습니다.

## 기능

| 종류 | 인덱싱 대상 | 검색 방법 |
|---|---|---|
| 이미지 | 이미지 임베딩 + OCR 텍스트(ML Kit, 한국어·라틴) | 설명, 이미지 속 글자 |
| 텍스트 파일 | txt, md, html, xml, csv/tsv, srt/vtt를 겹치는 청크로 | 의미, 키워드 |
| 문서 | PDF 쪽(텍스트, OCR 폴백, 쪽 이미지), docx/pptx/xlsx·ODF는 텍스트 + 텍스트 카드 이미지 | 의미, 키워드, 쪽 |
| 음성 | 음성 전사(SenseVoice), 오디오 클립 임베딩(740M 모델) | 말한 내용, 소리, 시간 |
| 영상 | 장면 클립(클립당 최대 8프레임) + 음성 전사 | 화면 내용, 말, 시간 |
| 인물 | 사진 속 얼굴(온돌샘이 찾고 알아봄)을 폰에서 사람별로 묶음 | 인물 메뉴(이름 짓기, 합치기, "이 사람 아님", 묶기 기준 느슨하게·엄격하게), 말벗다리에서: "민수 사진 모두 Pictures/Minsu로 옮겨" |

그 외: 허락한 다른 앱도 쓸 수 있는 인덱스(검색, 읽기, 그 앱에서 승인한 뒤 이동·휴지통; 설정 › 앱 › 연결된 앱), 검색 결과나 파일 상세정보에서 "채팅으로 묻기"(파일을 붙여 말벗다리를 엶), 실패한 파일 목록과 재시도, 선택형 리소스 표시(GPU/CPU, 메모리), 하이브리드 랭킹(의미 + 정확한 단어 + "두바이" 같은 사진 촬영 장소), 파일 종류·날짜 필터, 결과 공유·다른 앱에서 열기, 자동 인덱싱(수동·즉시·예약·유휴: 충전 중이고 배터리 수준에 따라 10~60분 쓰지 않을 때), 영어/한국어 UI, 다크 모드. 모델 선택과 메모리 유지 방식은 온돌샘에서 정합니다.

## 동작 방식

파일은 *세그먼트*(청크, 쪽, 클립)로 나뉘어 int8 임베딩과 함께 Room에 저장됩니다. 질의를 임베딩해 신호 그룹(시각·텍스트·음성)별로 모든 세그먼트와 비교하고, SQL 키워드 결과와 합쳐 파일 단위로 묶어 가장 잘 맞은 쪽/시간을 보여 줍니다. [아키텍처](docs/architecture.md) 참고.

## 요구 사항

Android 10 이상(minSdk 29)과 **온돌샘** 앱(모델은 온돌샘에서 받음). 모델: EmbeddingGemma 2 440M(388MB) 또는 740M(오디오 포함), 음성 인식용 SenseVoice(163MB), 인물용 얼굴 모델. 채팅은 말벗다리와 온돌샘의 채팅 모델이 필요합니다. 텍스트·문서는 "모든 파일 접근"이 필요합니다.

## 빠른 시작

```bash
source scripts/env.sh && ./gradlew assembleDebug && scripts/emu-start.sh && scripts/run.sh
# 온돌샘(별도 레포)도 빌드·설치하고 그 안에서 모델을 받습니다
```

앱에서: 첫 실행 마법사가 인덱싱할 대상(종류·폴더), 온돌샘 연결 확인, 자동 인덱싱 방식을 차례로 묻습니다. 이후 인덱싱 시작, 검색. 자세한 내용은 [getting-started](docs/getting-started.md)(영어).

## 프라이버시

모든 처리는 기기에서 이뤄지며, 눈소리에는 네트워크 권한이 없습니다. 모델은 온돌샘이 내려받습니다. [privacy](docs/privacy.md) 참고.

## 한계

Office 문서는 렌더링하지 않고(텍스트와 생성한 카드만 사용) 구형 .doc/.ppt/.xls, hwp는 지원하지 않습니다. 메모리 전체 탐색은 약 30만 세그먼트가 목표이며 짧은 영상 구간은 놓칠 수 있습니다. [roadmap](docs/roadmap.md) 참고.

## 이름의 뜻

**눈소리**는 한국어 명사 **눈**과 **소리**를 합친 이름입니다. 이 앱은 눈으로 보는 것(사진, 문서 페이지, 영상 프레임, 이미지 속 글자)과 귀로 듣는 것(말소리와 오디오)을 하나의 인덱스로 임베딩합니다. 그래서 "파일을 보고 듣는다"는 두 감각을 이름에 담았습니다. 다른 앱들처럼 영어로도 발음하기 쉬운("noon-so-ree") 일상적인 한국어 단어 두 개의 조합입니다.

역두문자는 하는 일을 풀어 씁니다: **N**ative(폰 안에서만), **U**nified(이미지·문서·음성·영상을 함께), **N**atural-language **S**earch, **O**ffline, **R**ecall & **I**ndex.
